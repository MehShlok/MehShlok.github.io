ADAPT — Adaptive Driver Anomaly Perception Technology 2025–

Supervised by Dr. Santonu Sarkar · Funded by Mercedes-Benz

Imitation learning framework for quantifying erratic driver behaviour, leveraging a transformer with a hierarchical weighted bottleneck fusion mechanism for multi-modal data.

Implicit Dehazing for Precise Image Classification 2023–24

Supervised by Dr. JK Sahoo · BITS Pilani

Hybrid CNN–PinGTSVM model for hazy parking slot classification that removes the need for a separate dehazing step entirely, achieving 98.20% accuracy vs. 88.63% for prior dehazing-based approaches.

Confluence of Epidemiological Modeling and Deep Learning 2023

BITS Pilani & Yale University

Modified Epi-DNNs for Indian Covid-19 data and proposed a novel SEIRD model. Presented to Dr. Abhishek Pandey, Associate Director (CIDMA), Yale — selected for a summer course on Epidemiological Modeling.

epidemiology deep learning
IoT Sensor Fault Detection for Smart Buildings 2024

Supervised by Dr. Christer Ahlund, Dr. Karan Mitra, Dr. Saguna (LTU Sweden), Dr. Neena Goveas

BrickSchema-modeled IoT sensor data for fault classification using ML techniques. Integrated semantic modeling and real-time data streams for fault monitoring. Industry-funded, deployed in Sweden (Ace-cybersafe).

Project Kratos — Mars Rover 2023–25

Mars Rover Team, BITS Goa

Deep learning–based hand gesture recognition for rover control (Gated LSTM). Achieved probabilistic mapping with point cloud data and elevation maps using a Zed 2i stereo camera. Won International Rover Challenge'24, featured in Times of India.
